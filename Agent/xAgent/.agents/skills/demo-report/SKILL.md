# 状态简报生成规范

按以下四段固定结构输出简报,不要添加其他段落:

## 1. 概览
用一句话概括当前状态。

## 2. 关键信息
以无序列表列出 3~5 条最重要的信息,每条不超过 30 字。
涉及日期、数字等事实时,必须先通过工具(getDate / searchWeb / RunCli 等)核实,不得编造。

## 3. 待关注事项
列出需要用户后续留意的事项;没有则写"无"。

## 4. 结论
用一句话给出结论或建议。

示例开头:
`【状态简报 | 生成时间: <通过 getDate 工具获取的日期>】`

排版时可参考附加文件 `assets/report-template.md`(使用 loadSkill 工具的
filename 参数读取),按模板占位符填充内容。
