# 宠物医院 · Windows 版运行说明

## 一、运行（三步）

1. 把整个 `windows` 文件夹复制到 Windows 电脑上（任意位置，例如 `D:\宠物医院\`）
2. **双击 `pethospital.exe`**
3. 在浏览器中手动打开 <http://127.0.0.1:8080/>

程序会在终端窗口打印访问地址，**不会自动打开浏览器**。请保持该窗口开启；按 `Ctrl + C` 可安全退出。

如果双击后窗口一闪而过，说明启动出错 —— 请改用命令行查看原因（见下方「常见问题」）。

> **首次运行会弹出 Windows 防火墙提示**，询问是否允许网络访问。
> 本程序只监听本机 `127.0.0.1`，**选择「取消」或「不允许」都不影响使用**，
> 因为浏览器访问本机地址不需要放行防火墙。

## 二、文件夹内容

```text
windows/
├── pethospital.exe     ← 主程序（64 位 Windows，已内嵌网页界面）
├── README.md           ← 完整接口与开发文档
├── README-Windows.md   ← 本 Windows 运行说明
├── LICENSE             ← MIT 许可证
└── data/
    └── pet.db          ← 数据库文件（含 1008 条模拟数据，可直接体验）
```

- **无需安装 Go、数据库或任何运行时**，单个 exe 即可运行
- 网页界面（HTML/CSS/JS）已编译进 exe 内部，**不需要额外的网页文件**
- `pet.db` 与 macOS / Linux 版**完全通用**，可互相拷贝

## 三、命令行用法

在文件夹空白处按住 `Shift` + 右键 → 「在此处打开 PowerShell 窗口」，
或直接在上方地址栏输入 `cmd` 回车：

```bat
pethospital.exe                                 :: 默认 127.0.0.1:8080
pethospital.exe -addr 127.0.0.1:9090            :: 换端口
pethospital.exe -seed                           :: 首次写入 8 条精选数据
pethospital.exe -seed -count 2000               :: 额外生成 2000 条模拟数据
pethospital.exe -db D:\mydata\pet.db            :: 指定数据库位置
pethospital.exe -no-color                       :: 关闭彩色输出
pethospital.exe -h                              :: 查看全部参数
```

按 `Ctrl + C` 可安全退出（会自动压实数据库并落盘）。

## 四、换成自己的空白数据

删除 `data` 文件夹，然后运行：

```bat
pethospital.exe -seed
```

程序会自动重建 `data\pet.db`。

## 五、常见问题

**双击后窗口闪退？**
右键 exe → 用「以管理员身份运行」试试；仍不行则用命令行启动，错误信息会直接显示出来。

**端口 8080 被占用？**
换端口启动：`pethospital.exe -addr 127.0.0.1:9090`，
然后访问 <http://127.0.0.1:9090/>。

**中文显示成乱码？**
在命令行里先执行 `chcp 65001` 切换到 UTF-8 编码。

**杀毒软件误报？**
Go 编译的单文件程序偶尔会被误判。可将其加入白名单，
或自行用 `make cross` / `build.sh` 从源码编译。

**这是 32 位还是 64 位程序？**
`pethospital.exe` 是 **64 位**版本，适用于绝大多数 Windows 10 / 11。
其他架构请从源码交叉编译。

## 六、数据安全提示

- 本程序**无登录、无鉴权**，且默认只监听本机地址，请勿直接暴露到公网
- 数据库就在 `data\pet.db` 这一个文件里，**直接复制该文件即可完成备份**
- 想迁移到另一台电脑：把整个 `windows` 文件夹拷过去即可，数据原样保留
